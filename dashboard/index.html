ABOUT AGENTYIELD

AgentYield combines Uniswap V4 Hooks with AI agents to create autonomous yield engines on X Layer.

How it works:
1. Anyone creates an agent in 1 click from this dashboard
2. The factory deploys a Hook + creates a V4 pool in 1 TX
3. Users deposit ETH/LP tokens and earn auto-compound yield
4. An AI bot reinvests treasury fees for compound growth
5. Each agent has its own on-chain personality via messages

Strategy Modes:
🚀 Aggressive — 0.01% fee, narrow range, max yield
⚖️ Balanced — 0.30% fee, medium range, standard
🛡️ Conservative — 1.00% fee, wide range, capital protection
