📖 How AgentLaunch Works

🎯 What is AgentLaunch?

AgentLaunch is a Uniswap V4 Hook for launching AI agent tokens with built-in bonding curves and fee distribution. Anyone can launch an agent token, configure metadata, and earn from swap fees.

🔧 How to Launch

  1. Create a Uniswap V4 pool on X Layer using this Hook address — set hooks = 0x6dC1E204B54C231A5e3dc2F0A1418649c079eCAf with dynamic fee flag enabled.
  2. Add initial liquidity to the pool (this registers the agent).
  3. Configure your agent here — fill in name, symbol, personality, and social links.
  4. Done! Your AI agent token is live. Start earning from swap fees.

💰 Fee Distribution

🟢 70% LP Fee goes to liquidity providers
🟣 20% Dev Share withdrawable by agent creator
🔵 10% Protocol Treasury global fee pool

📈 Bonding Curve

Each agent token has a linear bonding curve: price = basePrice + (supply/maxSupply) × priceRange. Early buyers get better prices. The curve auto-adjusts as liquidity is added or removed.
